# AnyEG vs our pipeline: extremum graphs of the same fields

Generated by `python3 -m comparison` on 2026-11-11 (NVIDIA GeForce RTX 3090). Raw numbers: `anyeg_vs_ours.json`. Findings are discussed in `observations.md`.

## Methods

- **AnyEG original**: AnyEG's own CUDA `compute()` (cudaHelper.cu, unchanged) on TTK's 14-neighbour grid, plus the port of its arc assembly
- **AnyEG torch**: `anyeg.TorchKernels`, the PyTorch port of the same four GPU modules (GPU)
- **Ours 6-nbr CPU**: `pipeline.extremum_graph` on our 6-neighbour grid graph, NumPy backend
- **Ours 6-nbr GPU**: the same with the torch backend (must give identical results)
- **Ours 14-nbr**: our algorithm on AnyEG's 14-neighbour grid, torch backend: isolates the algorithmic differences

## Value variants

- **raw**: values as stored
- **anyeg-preprocess**: v + 1e-8*rank (float64) cast to float32, as AnyEG's preprocess_vti.py
- **rank**: rank in (value, index) order: all distinct, our pipeline's order
