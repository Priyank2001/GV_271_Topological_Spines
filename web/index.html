Simplification

Blue: peaks left at each noise threshold. Red: links left at each variation threshold; links (saddles) above phi are cut, which can split the graph into separate pieces. A flat stretch means the structure is stable. Click the plot to set the noise threshold, shift+click to set phi. Grey: below this file's base threshold.

Spine drawing

Saturated persistence, as in the paper: a link to a peak that absorbed smaller ones runs along the ridge through them (small grey dots), so a ring stays a ring after its peaks merge. Off: straight links between the peaks that are left.
